# Numera

Single-file South African accounting web app (`Numera.html`) with contract billing, meter usage, service, assets, procurement and inventory, plus an optional SMTP mail relay (`numera-mail-relay.js`).

- Open `Numera.html` in a browser — no build step.
- Data is stored in the browser (localStorage), per company.
- `numera-mail-relay.js` is only needed for real email delivery (Settings → Email).
