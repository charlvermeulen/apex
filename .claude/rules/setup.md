# SETUP.MD

## Overview
This is a workflow for converting the application into a full-stack
Angular application.

### Stack
Use the following full-stack technologies.
- Frontend: Angular (latest version)
- Backend: NodeJs (latest version)
- Database: Neon (cloud based)

### Skills/Plugins
Use the Claude Skills/Plugins
- ui-ux-pro-max for UI/UX
- context7 for latest code documentation
- ponytail for better code output
- griller for ensuring better quality application output
- playwright for browser validation

### Workflow
- Convert the application into the stack.
- Each feature implementation will have seperate branch.
- Do this by breaking the application into sections/features.
- Ask questions using griller.
- Write and validate code using ponytail and context7
- Improve UI/UX design.
- Turn local storage into database.
- Validate each feature using playwright.
- Validate design using playwright.

### Important
Considering we are converting the application, it is important to first
create a new branch on Github for the updates. When the project is fully completed and converted into the new stack, we will then update
the main branch on the github repo.
